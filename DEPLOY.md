# Как бесплатно запустить онлайн

Нужны два бесплатных сервиса: **Render** (запускает сервер игры) и **Upstash Redis** (хранит крышки и рейтинг, чтобы они не пропадали при перезапуске). Для Render банковская карта не нужна.

## 1. Залей проект на GitHub
Файлы из папки `caravan` должны лежать в корне репозитория (`package.json`, `index.html`, `server/`, `shared/`, `art/`).

## 2. База для крышек и рейтинга (Upstash)
1. Зарегистрируйся на https://upstash.com (можно через GitHub).
2. Create Database → Redis, любое имя, регион поближе к Европе.
3. На странице базы открой вкладку **REST API** и скопируй `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.

Без этого шага игра тоже работает, но все крышки и рейтинг сбрасываются при каждом перезапуске сервера: на бесплатном Render диск не сохраняется.

## 3. Сервер (Render)
1. https://render.com → войти через GitHub → New → **Web Service** → выбери репозиторий.
2. Настройки:
   - Runtime: **Node**
   - Build Command: `npm install` (зависимостей нет, команда просто проходит)
   - Start Command: `npm start`
   - Instance Type: **Free**
3. Environment Variables:
   - `NODE_VERSION` = `22`
   - `UPSTASH_REDIS_REST_URL` = (из шага 2)
   - `UPSTASH_REDIS_REST_TOKEN` = (из шага 2)
4. Create Web Service. Через пару минут появится адрес вида `https://caravan-xxxx.onrender.com`.

Сервер сам отдаёт игру, поэтому **эта ссылка уже рабочая**: открой её в браузере и играй онлайн. Её же указываем в BotFather как адрес мини-приложения (шаг 4).

Бесплатный Render засыпает через 15 минут без запросов, первый заход после сна занимает около минуты. Чтобы засыпал реже, поставь бесплатный пинг (например, UptimeRobot) на `https://твой-адрес.onrender.com/health` раз в 5 минут.

## 4. Telegram Mini App
1. В Telegram открой @BotFather → `/newbot` → имя и username бота. Получишь токен вида `123456:ABC...`.
2. Добавь токен в Render: Environment → `TELEGRAM_BOT_TOKEN` = токен. Сервис перезапустится сам.
3. В BotFather: `/newapp` → выбери бота → название, описание, картинка 640×360 → **Web App URL**: `https://caravan-xxxx.onrender.com` (только https, Render даёт его сам) → short name, например `caravan`.
   Игра откроется по ссылке `https://t.me/ИмяБота/caravan`.
4. Чтобы игра открывалась кнопкой в чате с ботом: `/mybots` → бот → Bot Settings → Menu Button → Configure menu button → тот же URL.

С токеном вход идёт только через Telegram: сервер проверяет подпись данных Telegram, id игрока подделать нельзя, крышки привязаны к аккаунту Telegram, а не к браузеру. Если открыть ссылку Render просто в браузере, онлайн покажет «Открой игру через Telegram». Против бота можно играть и в браузере.
Без `TELEGRAM_BOT_TOKEN` (локальный запуск и отладка) работает старый вход по ключу браузера.
Отдельный бесплатный хостинг клиента (GitHub Pages) для мини-приложения не нужен: сервер Render отдаёт и игру, и онлайн.

## 5. Как это работает
- Раз в сутки (сутки начинаются в 14:00 по Москве) каждому игроку при первом заходе начисляется 100 крышек.
- Комнату можно создать открытой (она видна в списке «Комнаты») или приватной (вход только по коду). Ставка в крышках задаётся при создании, победитель забирает ставку. «Быстрый поиск» играет без ставки.
- «Рейтинг» показывает топ-10 по победам за прошедшие сутки и обновляется каждый день в 14:00 по Москве.
- Игрок определяется по аккаунту Telegram (подпись initData проверяется на сервере, см. шаг 4). Без токена бота: по ключу в браузере, тогда крышки можно накрутить очисткой данных.

## 6. Статистика онлайна
1. На Render добавь переменную `STATS_KEY` = любой длинный секретный пароль (например, 20+ случайных символов).
2. Открой `https://caravan-xxxx.onrender.com/stats?key=ТВОЙ_ПАРОЛЬ`. Страница сама обновляется раз в 30 секунд.
   - **Сейчас:** онлайн, игроков в партиях, открытых комнат, ищут соперника, всего игроков за всё время.
   - **По дням (МСК), 30 дней:** уникальных игроков, новых, сыгранных партий, пик онлайна.
3. Для скриптов: добавь `&json=1`, получишь те же данные в JSON.
Без `STATS_KEY` страница отключена (отдаёт 404). Не отправляй ссылку с ключом посторонним.
Статистика хранится вместе с крышками и рейтингом: при подключённом Upstash не пропадает при перезапуске. Без него обнуляется.

## Локальный запуск и переменные
`npm start`, затем http://localhost:3000. Переменные: `TELEGRAM_BOT_TOKEN`, `STATS_KEY`, `PORT`, `TURN_MS` (время хода, по умолчанию 90000), `DATA_FILE` (путь к JSON-файлу, если хранить данные на диске вместо Upstash), `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.
