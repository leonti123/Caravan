# Караван (онлайн)

Запуск: `npm start` (Node 22+), открыть http://localhost:3000. Тесты: `npm test`.

- `shared/rules.js` — правила (одни и те же в браузере и на сервере), `shared/ai.js` — бот.
- `server/server.js` — комнаты, быстрый поиск, проверка ходов, таймер хода 90 с, раздача клиента. Без зависимостей.
- `index.html` — клиент: бот, создание комнаты, вход по коду, быстрый поиск, переподключение.
- `art/` — сюда кладутся арты, см. `art/README.md`.

Сервер хранит партии в памяти: после перезапуска комнаты пропадают.
Хостинг: любой, где можно запустить Node (Render, Railway и т. п.): команда запуска `npm start`, порт берётся из `PORT`.
GitHub Pages для онлайна не подходит: он отдаёт только статику, а серверу нужен постоянно работающий процесс.

Онлайн, крышки, рейтинг и подключение к Telegram Mini App: см. [DEPLOY.md](DEPLOY.md).
