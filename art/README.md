# Арты

Клади файлы в эту папку, игра подхватит их сама. Чего нет, рисуется запасной графикой.

| Файл | Что это |
|---|---|
| `cards/S1.webp` … `cards/S13.webp` | пики: 1 = туз, 11 = валет, 12 = дама, 13 = король |
| `cards/H*.webp` | червы |
| `cards/D*.webp` | бубны |
| `cards/C*.webp` | трефы |
| `cards/JK.webp` | джокер (один рисунок на оба) |
| `back.webp` | рубашка колоды |
| `table.webp` | стол (рекомендую 2048×1024 и больше) |

Карта: полная картинка вместе с индексами и мастями, пропорция 2:3 (например 512×768), прозрачные скруглённые углы.
Формат по умолчанию WebP. Если нужен PNG, поменяй `EXT` в `index.html`.
Используй только свои работы или файлы со свободной лицензией. Арт, логотипы и звуки Fallout нельзя.
Если картинки не появились: открывай игру через сервер (GitHub Pages или `python -m http.server`), а не двойным кликом.

## Что сейчас лежит
`cards/*.webp` (54 шт.), `back.webp` — колода Caravan из мода HD Playing Cards Remastered, переведена из 512×1024 в 640×960 (2:3) со скруглёнными углами.
`backs-extra/back2..5.webp` — запасные рубашки (игрой не используются; чтобы выбрать другую, скопируй её как `art/back.webp`).
Стола (`table.webp`) в моде нет — рисуется запасной.
